cc-switch

一个桌面小工具，帮你管理 Claude Code、Codex 这些软件的「连接设置」。用了它，在多家服务商、多个工具之间切换就变成点一下按钮的事，不用再去手改配置文件。

当前显示的是 macOSWindows 的安装方式

先说清楚：你需要它吗

这一页不是必须做的。先对照下面的情况判断一下。

可以先跳过，如果……

你只用 DeepSeek 一家，而且只装了 DSH。

前面几步已经足够你上课用了。

建议装，如果……

你装了 Claude Code 或 Codex（配置要写好几行环境变量，还只对当前终端窗口有效）；

或者你想在多家模型之间比较；

或者你以后会换服务商。

💡
它解决的问题很具体 Claude Code 和 Codex 各有自己的配置文件，格式还不一样（一个是 JSON，一个是 TOML），变量名也不同。你想换个服务商，就得记住两个文件、改两遍，改错了还没有撤销。
cc-switch 把这些变成一个图形界面：选供应商、填 Key、点「启用」。

先搞懂「配置文件」这件事

这是理解 cc-switch 的前提，也是你以后遇到任何新 AI 工具都不会慌的底气。

每一个 AI 编程工具，都要知道三件事：请求发到哪台服务器、用哪把钥匙、要哪个模型。它们只是把这同样三件事，写在不同格式的文件里：

工具配置文件格式
Claude Code ~/.claude/settings.json JSON，三要素写在 env 块里
Codex ~/.codex/config.toml TOML，供应商写在 [model_providers.xxx] 段里
Gemini CLI ~/.gemini/.env 环境变量文件
DeepSeek Harness 设置 → 模型（图形界面） 不用手写文件，填表单就行

手写起来大概长这样——注意两个文件连括号风格都不一样：

Claude Code

{
  "env": {
    "ANTHROPIC_BASE_URL":
      "https://api.deepseek.com/anthropic",
    "ANTHROPIC_AUTH_TOKEN": "sk-xxxx",
    "ANTHROPIC_MODEL": "deepseek-flash[1m]"
  }
}

Codex

model = "deepseek-flash"
model_provider = "deepseek"

[model_providers.deepseek]
name = "DeepSeek"
base_url = "https://api.deepseek.com"
env_key = "DEEPSEEK_API_KEY"
😵
痛点在哪 ① 两个文件、两种格式、两组变量名
② 少一个逗号或写错一个括号，整个文件就废了
③ 想从 DeepSeek 换成别家，要再改一遍
④ 想同时用三个工具，每个都要单独配
⑤ 改坏了没有「撤销」按钮
🧭
所以本手册的顺序是「先手工，再自动化」 在 Claude Code 和 Codex 那两页，我让你先手写一遍配置——因为你要知道它到底改了什么。
搞懂之后再回来用 cc-switch 点按钮，就变成了「省事」，而不是「黑箱」。

安装

方式一：Homebrew（推荐）

brew tap farion1231/ccswitch
brew install --cask cc-switch

以后升级：

brew upgrade --cask cc-switch

方式二：下载安装包

打开项目的 Releases 页面：github.com/farion1231/cc-switch/releases，下载最新的 .dmg 文件，打开、把图标拖进「应用程序」。

macOS 版本已经过 Apple 签名和公证，正常打开不会有「无法验证开发者」的拦截。

方式一：安装包（推荐）

打开项目的 Releases 页面：github.com/farion1231/cc-switch/releases

找到最新版本下面的 Windows 文件，有两种：

  • ...Windows.msi —— 安装版，双击安装，会有开始菜单快捷方式
  • ...Windows-Portable.zip —— 免安装版，解压后直接运行里面的 CC-Switch.exe

不确定选哪个就用 .msi。如果你的电脑是 ARM 架构（比如骁龙处理器的笔记本），选带 arm64 的那个。

⚠️
Windows 首次运行可能被拦 如果 SmartScreen 弹窗说「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。这是因为它是一个个人开发者发布的程序，没有买微软的签名证书。

它不是 npm 包

🚫
不要运行 npm install cc-switch。cc-switch 是一个桌面应用程序，只能通过 Homebrew 或者下载安装包来装。npm 上如果有同名包，那不是它。

怎么用

  1. 添加一个供应商

    打开 App，点 Add Provider（添加供应商）。

    它会给你一个内置预设列表——很多常见的服务商都预置好了，选一个就自动填好了地址和格式。

  2. 填上你的信息

    通常只需要补这些：

    • 名称：随便起，能认出来就行，比如 DeepSeek 官方
    • base_url：接口地址。用预设的话已经填好了
    • API Key：你在 拿到 API Key 那一页拿到的
    • model id：要哪个模型，比如 deepseek-flash

  3. 启用它

    在列表里选中这个供应商，点 Enable（启用）。它就会去改写对应工具的配置文件。

  4. 让工具重新读配置

    大多数工具需要重启终端或者重启对应的 CLI。唯一的例外是 Claude Code——它支持热切换，改完直接就能用，不用重启。

回到官方登录

想切回 Anthropic 或 OpenAI 的官方账号？添加一个 Official Login 预设，启用它，重启 CLI，然后走官方的登录流程。之后你就可以在「官方」和「第三方」之间自由切换了。

它到底动了哪些文件

这一点值得知道——万一哪天出问题，你要去看的就是这些文件。

工具配置目录它写入的关键文件
Claude Code ~/.claude/ settings.json 里的 env 块（就是 Claude Code 那一页手写的那几个变量）
Codex ~/.codex/ config.toml（供应商配置）、auth.json（凭据）
Gemini CLI ~/.gemini/ .env、settings.json

它自己的数据全部存在 ~/.cc-switch/ 目录里，包括一个数据库、设置文件和自动备份。所有东西都在你自己的电脑上，不会上传。

🛡️
设计上比较克制的一点 它的原则是「最小侵入」：即使你把这个 App 卸载了，你的 Claude Code 和 Codex 依然能正常工作——因为它们读的是标准配置文件，而 cc-switch 只是替你改那些文件。而且它始终会保留一个可用的配置，不会让你删到工具打不开。

一个必须知道的安全提醒

🎣
只从官方渠道下载 cc-switch 是开源免费的，作者不会向你收费，也不会向你索要登录凭据。
任何向你收费、要求充值、或者要你输入账号密码的「CC Switch」网站或客户端，都是假冒的。
官方只有两个地方：GitHub 仓库 github.com/farion1231/cc-switch，和官网 ccswitch.io。

常见问题

装完打不开，或者提示「已损坏」

macOS：确认你是从 Releases 页面下载的 .dmg，而不是从第三方站点下的。官方版本经过签名公证，不该有这个提示。

Windows：见上面关于 SmartScreen 的说明，点「更多信息 → 仍要运行」即可。

切换了供应商，但工具没变化

  • 没有重启对应的 CLI。除了 Claude Code，其他都要重启
  • 注意：重启「终端窗口」和重启「CLI」可能是两回事，最稳的是关掉终端窗口重新开一个
  • 检查你启用的供应商是不是你以为的那一个（界面上会显示当前启用的是哪个）

Linux 上装不上

Linux 用户下载 .deb、.rpm 或 .AppImage。用 AppImage 的话，如果界面点不动或者缩放时黑屏，可能是 Wayland 和 NVIDIA 驱动的兼容问题，可以试着强制走 X11 后端。

我想知道它改了什么，去哪看

直接打开上面表格里那几个文件看就行。它就是普通的 JSON / TOML 文本文件，用记事本或 VS Code 都能看。这也是为什么前面让你先手工配一遍——先知道发生了什么，再用工具替你省事。
