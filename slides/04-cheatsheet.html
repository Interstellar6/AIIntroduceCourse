基本概念

模型输入文字 → 输出文字。没记忆、没手、一次调用就结束
Agent模型 + 循环 + 工具 + 持久日志，能把事真的做完
Agent Loop组装上下文 → 请求模型 → 调工具 → 结果写回 → 再请求
Harness把模型包装成能干活的产品的那一整套工程
轮次 Turn你发一句话，它一直干到停下来
步骤 Step一次模型请求 + 它引发的工具执行
预设 Preset给一个会话装哪些工具、什么规矩（标准/极简/PTC/创造）

上下文与安全

上下文窗口模型一次能「同时看到」的全部文字，有上限
压缩 Compaction快满了就把前面的对话总结掉腾地方，代价是丢细节
系统提示词你看不见、但它每轮都在读的那段话
流式 Streamingtoken 一个个吐出来，不代表更快，只是更早看见
沙箱 Sandbox它能碰哪些目录、哪些命令
审批 Approval哪些操作必须先问过你
子代理 Subagent派一个干净的分身去干独立的事，不污染主对话
计划 / 目标模式动手前先给你看方案 / 给个长期目标让它自己接着干

两条最实用的经验：需要留下的东西让它写进文件；换任务就开新会话。

速查卡 2 / 4 · 三要素与协议

配任何工具，只需要这三样 + 一个协议

base_url

发到哪台服务器

https://api.deepseek.com

别凭印象加 /v1

API Key

你是谁，从谁账上扣钱

sk-xxxxxxxxxxxx

就是你的钱，别外传

model id

要哪一个模型

deepseek-flash
deepseek-v4-pro

deepseek-chat 已停用

DeepSeek 三种协议地址（一个 Key 通用）

OpenAI 格式https://api.deepseek.com
Responses（Codex）https://api.deepseek.com
Anthropic（Claude Code）https://api.deepseek.com/anthropic

速查卡 3 / 4 · 命令（装工具）

从零到有环境

① 第一次调用（任何系统）

export DS_KEY="sk-你的Key"
curl https://api.deepseek.com/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $DS_KEY" \
  -d '{"model":"deepseek-flash","messages":[
       {"role":"user","content":"你好"}]}'

② DeepSeek Harness（网页界面）

mkdir -p ~/ai-lab && cd ~/ai-lab
npx @deepseek-ai/dsh web
# 浏览器打开 http://127.0.0.1:3080

先 cd 到工作目录，再启动。

③ cc-switch（管配置的开关面板）

brew tap farion1231/ccswitch
brew install --cask cc-switch
# 或去 GitHub Releases 下 .dmg / .msi

④ Claude Code

curl -fsSL https://claude.ai/install.sh | bash
claude --version && claude doctor

⑤ Codex

curl -fsSL https://chatgpt.com/codex/install.sh | sh
codex   # 先跑一次，建出 ~/.codex 目录
人工智能导论 · 速查卡

Windows 对应命令：Claude Code → irm https://claude.ai/install.ps1 | iex；Codex → powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"。DSH 的前置条件是 Node 22 或更新。

速查卡 4 / 4 · 命令（接上模型）

让两个终端 Agent 都用上 DeepSeek

Claude Code → DeepSeek

export ANTHROPIC_BASE_URL=\
  https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN="sk-你的Key"
export ANTHROPIC_MODEL=deepseek-flash[1m]
export ANTHROPIC_DEFAULT_OPUS_MODEL=\
  deepseek-flash[1m]
export ANTHROPIC_DEFAULT_SONNET_MODEL=\
  deepseek-flash[1m]
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-flash
export CLAUDE_CODE_SUBAGENT_MODEL=deepseek-flash
export CLAUDE_CODE_EFFORT_LEVEL=max

验证

cd 你的项目目录 && claude
/status   # 看 base URL 是不是 api.deepseek.com

Codex → DeepSeek（官方一键脚本）

bash <(curl -fsSL https://cdn.deepseek.com/\
api-docs/codex-deepseek-setup.sh)

# 菜单：1 = flash，2 = v4-pro，9 = 还原默认

建议的安全组合

codex --sandbox workspace-write \
      --ask-for-approval on-request

允许它在工作目录里干活，但每走一步先问你。

一句话提醒

这两条路都不需要中转站。命令会随版本变化，配不通时以官方文档为准。

人工智能导论 · 速查卡

PowerShell 里 export A=B 要写成 $env:A="B"。

Claude Code 的这几行只对当前终端窗口有效，关掉就没了；想永久生效写进 ~/.zshrc，或用 cc-switch 一键写进 ~/.claude/settings.json。
