Codex

OpenAI 出的 Agent，既有终端版也有图形界面版。它的特点是权限控制做得特别细——你可以非常精确地规定它「能碰哪里」和「什么时候必须先问你」。装它有一点跟别的工具不一样，这一页会讲清楚。

当前显示的是 macOS / LinuxWindows 的命令

装之前必须知道的一件事

Codex 和模型说话时用的格式叫 Responses。这是一个比较新的格式，而它现在只支持这一种——更早的 Chat Completions 格式已经被官方移除了。

⚠️
这一条会影响你以后选服务商 网上很多老教程会教你写 wire_api = "chat" 来「兼容旧服务」——这个写法已经失效了，写上去 Codex 会直接启动失败。
好消息是 DeepSeek 原生支持 Responses 格式，所以下面这套配置是直连的，不需要任何中间转换。
以后如果你想接别的服务商，先确认它「支持 Responses 接口」，否则 Codex 用不了它。

安装

推荐：官方安装脚本

curl -fsSL https://chatgpt.com/codex/install.sh | sh

或者用 Homebrew

brew install --cask codex

或者用 npm

npm install -g @openai/codex

推荐：官方安装脚本

在 PowerShell 里运行这一整行（注意引号要完整）：

powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"

里面那段 -ExecutionPolicy ByPass 是为了让这条安装脚本能执行。它只对这一次生效，不会永久改你的系统设置。

或者用 npm

npm install -g @openai/codex

Codex 对 Node 版本要求不高，16 以上就行。

✅
Windows 用户体验提示 Codex 对 Windows 的原生支持比 Claude Code 好。如果你在 Claude Code 那一页卡住了，先用 Codex 完全没问题。

关键的一步：先随便跑一次

装完之后，先在终端里运行一次 codex，跟它随便说句话，然后退出（按 Ctrl + C）。

codex

这一步看起来毫无意义，但它是必须的：Codex 的配置目录 ~/.codex 是在它第一次运行时才创建的，而下一步的配置脚本需要这个目录已经存在。

💡
如果它在这个时候让你登录 ChatGPT，跳过或者随便走一下都行。我们下一步就把它改成走 DeepSeek，用不到 ChatGPT 账号。

接上 DeepSeek

DeepSeek 官方提供了一个一键配置脚本，会自动做好全部配置。

bash <(curl -fsSL https://cdn.deepseek.com/api-docs/codex-deepseek-setup.sh)
irm https://cdn.deepseek.com/api-docs/codex-deepseek-setup.ps1 | iex

运行后会出一个菜单，按数字选择：

选项作用
1用 deepseek-flash 模型，推荐选这个（它同时支持图片输入）
2用 deepseek-v4-pro 模型（更强，也更贵）
9恢复默认配置，把 DeepSeek 相关设置删掉

第一次运行会提示你输入 API Key，就是 sk- 开头那一串。

它到底改了什么

知道这个，以后出问题你自己就能查：

  • 备份你原来的 ~/.codex/config.toml 到 ~/.codex/backup-deepseek/——所以随时可以还原
  • 写一个 ~/.codex/models.json，告诉 Codex「DeepSeek 这个模型有什么能力」（上下文多长、支持不支持图片、支持哪些思考档位）
  • 在 config.toml 里加上一段 [model_providers.deepseek]，也就是「去哪里找 DeepSeek」

它只改必要的字段，你原有的其他配置（比如 MCP 服务、项目信任设置）都会保留。写入前会校验语法，校验不过就中止，不会把你的配置改坏。

♻️
再运行一次脚本就能重新配置；选菜单里的 9 可以恢复到你安装前的状态。所以放心试，改坏了能退回去。

验证

进入你的练习文件夹，启动 Codex：

cd ~/ai-lab
codex

然后问它一句：

用一句话介绍你自己，并告诉我你现在用的是哪个模型。

能正常回答，就说明接上了。可以再看看登录状态：

图形界面版：不用待在终端里

Codex 不只有命令行。它有好几种界面，而且——这是最省事的一点——它们共用同一份配置文件。

也就是说：你刚才跑的配置脚本，一次就把下面所有形态都配好了，不需要为每个界面重配一遍。

怎么装图形界面版

界面怎么装
VS Code / Cursor / Windsurf 在扩展面板里搜 Codex（发布者是 OpenAI），或者从 VS Code 应用市场搜 openai.chatgpt。装完编辑器里会多一个 Codex 图标，点开就是侧边栏面板
JetBrains 系列 用 JetBrains 的 AI Assistant，在里面选 Codex 作为 agent
Xcode 用 Xcode 的编码助手，选 Codex 作为 agent
ChatGPT 桌面端 装 ChatGPT 桌面应用。它和命令行共享 ~/.codex 那份配置
✅
装上之后不用再配一遍 直接打开侧边栏，选一个项目文件夹，然后开始提问就行。它读的是你已经配好的 DeepSeek。

图形界面版的好处是上下文已经在你眼前：可以把打开的文件、选中的代码、最近的对话直接带进提问里，改动也能在你的代码旁边直接看 diff、逐个决定接受还是拒绝。适合一边读代码一边小步修改。

终端版适合让它跑一长串命令、做比较大的改动。两个都在，按场景切就行。

💡
给课上同学的建议 如果你更喜欢图形界面，完全可以只用 VS Code 扩展——安装更简单，而且能直接沿用你已经配好的 DeepSeek。终端版那几步装不上的话，不影响你用扩展。

给它多大的权力：两个开关

这是 Codex 做得最好的部分，也是所有 Agent 工具都有的两个概念。

沙箱：它能碰哪里

取值含义
read-only只能看，不能改任何东西
workspace-write只能在当前工作目录里写（推荐）
danger-full-access整个系统随便动（危险，除非你很确定）

审批：什么时候必须先问你

取值含义
untrusted除了确定安全的只读命令，其他全都要问你
on-request由模型自己判断何时该问（默认值）
never从不问，直接执行（只适合无人值守的自动化）
🛡️
给学生的建议组合 
codex --sandbox workspace-write --ask-for-approval on-request
这是官方的「低摩擦组合」：允许它在工作目录里干活，但每走一步都先问你。等你摸清它的脾气了，再逐步放宽。
一句话记住：沙箱管「能碰哪里」，审批管「什么时候停下来问你」。

进阶：手工配置

一键脚本已经够用。但如果你想知道背后是什么样子，或者需要接别的服务商，可以看这里。

供应商配置必须写在用户级的配置文件里：

文件位置
主配置~/.codex/config.toml
模型目录~/.codex/models.json
登录凭据~/.codex/auth.json
🚫
最常见的坑 把 model_provider 写进项目目录里的 .codex/config.toml——这个会被忽略，而且启动时会打印警告。供应商配置必须在用户级目录（也就是你的个人主目录）下的那份文件里。

一个最小的配置长这样（假设你已经设了环境变量 DEEPSEEK_API_KEY）：

# ~/.codex/config.toml
model = "deepseek-flash"
model_provider = "deepseek"

[model_providers.deepseek]
name = "DeepSeek"
base_url = "https://api.deepseek.com"
env_key = "DEEPSEEK_API_KEY"

# 沙箱与审批
approval_policy = "on-request"
sandbox_mode = "workspace-write"
📝
TOML 格式有个容易忘的规则：不带方括号的顶层设置必须写在所有 [方括号段落] 之前。顺序写反了会解析失败。

常见问题

配置脚本报错说找不到目录

你还没跑过第一次 codex，~/.codex 目录不存在。回到上面「先随便跑一次」那一步。

启动时提示 wire_api 相关错误

你的配置里有 wire_api = "chat" 这种老写法。删掉那一行（或者改成 "responses"），或者直接重跑一遍配置脚本、选菜单里的 9 恢复默认后再重配。

提示模型不存在

检查 model 那一行的名字。必须是 deepseek-flash 或 deepseek-v4-pro——deepseek-chat 已经在 2026 年 7 月停用了。

它老问我要权限，很烦

那是审批在工作，不是 bug。刚开始用的时候让它多问几次是好事。不要一上来就设成 never 或者 danger-full-access。

和 Claude Code 能共存吗

能，它们的配置在不同的目录，互不干扰。如果你要同时用好几个工具、还要在多家服务商之间切换，装 cc-switch 会省很多事。
