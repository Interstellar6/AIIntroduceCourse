安装 Node.js

Node.js 是一个运行环境，本身和 AI 没关系。但你要装的几个工具里，有两个是「用 JavaScript 写的程序」，需要它才能跑起来。装一次，以后不用管。

当前显示的是 macOS / LinuxWindows 的命令

要装哪个版本

装 LTS 版本，并且要 22 或更新。原因是 DeepSeek Harness 明确要求 Node 22.19 以上或 24 以上。版本太老会出现一些很难懂的报错。

⚠️
别用系统自带的旧版本 有些 Linux 发行版的软件源里 Node 版本很旧。如果你之后 node -v 出来是 18 或 20，就回来按下面重新装。

安装

方式一：Homebrew（推荐）

如果你已经装了 Homebrew：

brew install node

方式二：官方安装包

打开 nodejs.org/zh-cn/download，下载标着 LTS 的那个 macOS 安装包（.pkg），双击、一路下一步。

不确定自己的 Mac 是 Intel 还是 Apple 芯片？点左上角苹果图标 →「关于本机」，看「芯片」那一行。

方式一：官方安装包（推荐）

打开 nodejs.org/zh-cn/download，下载标着 LTS 的 Windows 安装包（.msi），双击、一路下一步。

安装过程中如果看到「Automatically install the necessary tools」这类勾选项，可以取消勾选——那是给要编译 C++ 模块的人用的，我们用不上，勾上反而会多装几个 GB 的东西。

方式二：winget

Windows 10/11 自带 winget，在 PowerShell 里运行：

winget install OpenJS.NodeJS.LTS

验证

先关掉你已经打开的终端窗口，再重新打开一个。这一步很重要——环境变量是终端启动时读的，不重开的话新装的命令找不到。

node -v
npm -v

两行都打印出版本号就成功了，比如：

# 你的版本号可能比这个更新，只要 ≥ 22 就行
v22.19.0
10.9.3
✅
看到版本号 = 这一步完成 接下来装工具的时候，如果报「找不到命令 npx」或者「node is not recognized」，八成就是忘了重开终端，或者装的根本没成功。回到这一页重来一遍。

可选：换成国内镜像加速

默认的下载源在国外，装工具时可能会很慢甚至超时。换成国内镜像会快很多：

npm config set registry https://registry.npmmirror.com

想改回去：

npm config set registry https://registry.npmjs.org
💡
镜像只影响「下载软件包」 它不会影响你和模型的通信。也就是说，换镜像不会让 AI 变快或变慢，只是让安装过程更快。而且镜像上的包可能比官方晚几个小时到一天更新，学习用途完全没问题。

常见问题

装完之后 node -v 还是找不到命令

  • 最常见：没重开终端。关掉所有终端窗口，重新开一个
  • Windows：安装时如果没勾「Add to PATH」，需要重新运行安装包并勾上
  • macOS：如果你用的是 .pkg 安装包，可能需要重启一次终端；用 Homebrew 的话确认 /opt/homebrew/bin 在 PATH 里

我电脑上已经有 Node，但版本是 18 / 20

两个选择：直接再装一遍新版本覆盖（推荐），或者用版本管理工具（macOS/Linux 用 nvm，Windows 用 nvm-windows）来同时保留多个版本。学习阶段直接覆盖最省事。

报权限错误（macOS / Linux）

如果看到 EACCES 或者让你加 sudo，不要加 sudo。sudo npm install -g 会把文件装成 root 所有，之后每次都要 sudo，而且有安全风险。正确做法是用 Homebrew 装 Node，或者用 nvm 管理。

公司或学校网络装不上

先换国内镜像（上面那一条）。如果还不行，可能是网络需要代理，这时候要先配置 npm 的代理设置，或者换个网络环境试试。

这一步做完，你就有了安装所有工具的基础环境。
