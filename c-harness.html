Harness：模型怎么变成产品

同一个模型，装在不同软件里，能力差很多——这不是你的错觉。这一页讲清楚那个「中间层」是什么，顺便解释后面要装的几个工具之间到底是什么关系。

Harness 是什么

这个词原意是马具——把一匹马拉上车的那整套东西：笼头、缰绳、鞍、车辕。

马有力量，但没有马具，你既坐不上去，也控制不了方向。

在 AI 里，harness 指的是「把模型包装成一个能干活的产品」所需要的那一整套工程。它不是一个具体软件的名字，而是一类东西的统称。Claude Code 是 harness，Codex 是 harness，DeepSeek Harness 也是 harness。

这一整套工程具体包括什么

模型适配

把各家五花八门的接口（DeepSeek / Claude / GPT）统一成一种内部格式。

这就是为什么同一个工具能接不同厂商的模型。

Agent 循环

上一页讲的那五步转圈，就是它实现的。

工具与执行

读写文件、跑终端、搜索、跑代码——以及怎么安全地执行。

沙箱与审批

哪些能碰、哪些先问你、哪些一律禁止。

会话与日志

把每一步存下来：能恢复、能分叉、能追责。

上下文管理

什么时候截断、什么时候压缩、压缩时丢掉什么。

界面

终端里的，还是网页里的；怎么让你看见它正在干什么。

配置与插件

怎么换模型、怎么加自己的工具、怎么改它的规矩。

🚗
一个比喻 模型是发动机；harness 是底盘、变速箱、方向盘、仪表盘和刹车。
发动机再好，没有底盘你开不走；刹车不好，你不敢踩油门。

四层关系

把这几个词叠起来，它们的关系是这样的（越往下越「底层」）：

你面前那个界面终端里的 Claude Code / Codex · 网页里的 DeepSeek Harness
Harness循环 + 工具 + 沙箱 + 会话 + 压缩 + 配置
Agent 循环组装 → 请求 → 调工具 → 写回 → 再请求
模型DeepSeek · Claude · GPT —— 真正「聪明」的那部分

模型决定它有多聪明

这是别人训练好的，你只能选，不能改。

Harness 决定它能干多少活、以及会不会闯祸

这是同一个模型在不同工具里表现不同的真正原因。

所以以后遇到「为什么同样是 DeepSeek，在那个软件里好像更强」这种疑问，答案就在这里——大概率是那个 harness 的循环设计得更好，或者给模型看的上下文更合适。

Agent 模式（预设）：给一个会话装什么

同一个 harness 里，你也可以调整「这一次给它装哪些工具、什么规矩」。这个打包好的配置叫预设或模式。

DSH 出厂带了四个：

模式它有什么什么时候用
标准 全套：读写文件、终端、搜索、技能、计划、目标、子代理、工作流 默认就用它，九成任务够用
极简 只有两个工具：持久终端 + 文件编辑器 看明白「Agent 到底靠什么活着」；也是最省的模式
PTC 标准模式的能力，但让模型写一段程序来一次性组合很多步操作 步骤很多、又很重复的活（批量处理一堆文件）
创造 标准模式的能力 + 运行时自省 + 改造自己的能力 进阶：想自己写一个新模式或新插件

另外还有两个会话级的开关，在会话与上下文里讲过：计划模式（动手前先给你看方案）和目标模式（给个长期目标自己干）。

一个反直觉的结论：为什么必须玩一下「极简模式」

极简模式只有两个工具，却几乎什么都能干。原因是终端本身就是万能工具——能读文件、能写文件、能装东西、能跑代码、能上网。

给它一个终端，就等于给了它一双手。

🎯
工具越多 ≠ 越强 工具越多，模型越容易选错，越容易在一个小问题上乱试十种办法。多出来的工具，同时也多出了出错的面。

而且工具列表本身也要占用上下文——少给工具，还更省钱。

一句话：Agent 的能力不是来自「很多按钮」，而是来自「一个循环 + 一双能执行命令的手」。

所以装好 DSH 之后，强烈建议你开一个新会话、切到极简模式、把同样的任务再发一次。看着两个工具把事做完，你对 Agent 的理解会上一个台阶。

「一切皆插件」：一个值得知道的设计

DSH 的设计准则叫一切皆插件。意思是它的内核被刻意做得极小，只包含：

  • 几个抽象服务（会话、工具注册表、提示词组装、模型路由）
  • 一个 Agent 循环插件

其余的全部是插件，包括：模型适配器、每一个工具、会话日志与存储、压缩策略、沙箱与审批、网页界面，甚至那个循环本身。

扩展的方式

在旁边挂一个插件，而不是给内核打补丁。内核永远保持干净。

卸载即撤销

插件带来的东西，在它被卸下时全部撤回，不留残渣。

为什么这件事值得知道？因为它把「选 harness」这个决定的性质说清楚了：

🧩
传统软件像一栋已经盖好的楼，你想加个窗户得砸墙；插件式的 harness 像乐高，你想加什么就在旁边插一块。
所以选 harness，其实是选生态——你选的不只是今天的功能，而是以后能往哪儿长。
