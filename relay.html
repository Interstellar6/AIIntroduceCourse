先说结论 这门课不需要中转站。DeepSeek 官方直连、支付宝付款、便宜，而且它同时提供了 OpenAI、Anthropic、Responses 三种接口格式——Claude Code 和 Codex 都能直接接上。
下面这些只是给「想试试别的模型」的同学留的备选项。

什么情况下你会想看这一页

  • 你听过 Claude、GPT 这些模型，想知道和 DeepSeek 用起来有什么不一样
  • 你想对比同一个任务在不同模型上的表现
  • 你没有外币信用卡，但想试试国外的模型
  • 你在做的某个具体任务，觉得换个模型可能效果更好

什么是「中转站」

它是一个中间商：你只跟它打交道，它在背后替你连接各家模型的服务。你拿到一个地址（base_url）和一把钥匙（API Key），就能调用它支持的多种模型，用一种方式付费。

它解决的真实问题是「省事」——不用为每家模型分别注册、分别付款、分别管理密钥。

怎么用？ 注册之后，站点会给你一个 base_url 和一个 API Key。把它们填进 cc-switch 的「自定义供应商」，或者直接写进对应工具的配置里就行。

🌐
打不开是正常的 这类服务的可访问性、注册条件、支付方式各站不同，可能会遇到打不开、加载不出来或提示地区限制的情况。这不代表你的操作有问题，换个网络环境再试。

用之前请务必知道这几件事

中转站是你和模型之间的中间人。这不是危言耸听，而是它的工作方式决定的：

  • 你的每一句对话它都看得见。这不是「它要不要记录」的问题——它在中间转发，技术上必然能读到明文。
  • 它可能跑路。余额可能取不回来。充值金额就是你能承受的最大损失。
  • 它可能超售、限速，甚至用便宜模型冒充贵的模型。你很难验证自己实际用的是什么。
  • 你的 Key 可能被记录、被转卖。
  • 部分服务涉及合规问题。调用未在境内备案的境外模型，本身处在监管的灰色地带。
🔐
五条原则 ① 能官方就官方——学生做实验，DeepSeek 官方几块钱就够
② 真要买，小额充值，把它当一次性消费，别当银行
③ 不放敏感数据——个人信息、还没发表的实验数据、别人的代码，都不要经过它
④ 没有公开退款条款的平台，默认「钱要不回来」
⑤ 别用别人送的 Key，也别把你的 Key 给别人
💭
最后一句实话 「便宜到离谱」本身不是优点，而是一个需要解释的现象。真正会把学生带进坑的诱因，就是「便宜」和「额度看起来用不完」这两件事。

决定用官方还是中转，其实不影响你学这门课——工具和配置方法完全一样，只是 base_url 和 Key 换了而已。
