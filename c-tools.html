工具地图与怎么选

你会听到五个名字：Claude Code、Codex、DeepSeek Harness、cc-switch、中转站。这一页把它们放进同一张地图，让你知道谁是谁、谁解决什么问题。

先分清：哪些是「AI」，哪些只是配件

这是最容易搞混的一点。这五个名字里，只有三个是真正装模型的地方，另外两个是配件。

名字它是什么干什么的什么时候用
Claude Code Harness Anthropic 的 Agent，终端 + 编辑器扩展两种界面，工具设计成熟，读代码 / 改代码最稳 写代码、改项目、读别人的代码库
Codex Harness OpenAI 的 Agent，命令行 / 编辑器扩展 / 桌面端共用一份配置，沙箱与审批做得细。只支持 Responses 协议 写代码、跑命令；喜欢图形界面的可以直接用编辑器扩展
DeepSeek
Harness		 Harness DeepSeek 的开源 harness：有网页界面、多种模式、一切皆插件 上手、学习、想看清 Agent 到底在转什么
cc-switch 配件 一个开关面板：管理各家供应商配置，一键切换 同时用好几个工具、或想在多家模型之间切换
中转站 配件 一个卖 API 的中间商：一个入口后面接多家模型，统一计费 想用一个 Key 通吃多家模型时
❗
最重要的一句话 前三个不是「三个不同的 AI」，是三个不同的 harness——它们可以接同一个模型。
本手册里，三个都接的是 DeepSeek。所以你装它们不是为了获得三个更聪明的模型，而是为了得到三种不同的干活方式。

它们各自的位置

用上一页那张层次图来放，就很清楚了：

  • 1
    模型层 DeepSeek、Claude、GPT……你买的是这一层的东西。API Key 就是买它的凭证。
  • 2
    Harness 层 Claude Code、Codex、DeepSeek Harness。它们都实现同一个 Agent 循环，区别在工具设计、权限控制、界面和手感。
  • 3
    配件层 cc-switch 管配置，中转站管供应。它们本身不产生任何 AI 能力，只是让「连接」这件事更省事或更便宜。

两个 harness 的手感差在哪

既然三个都接同一个模型，为什么不只装一个？因为它们的取舍不一样。

DeepSeek HarnessClaude CodeCodex
界面浏览器网页终端终端
最大特点模式可切换，能看清内部工具设计成熟，改代码最稳权限控制最细
适合第一次用、学习原理长期写代码、改项目需要精确控制权限的场合
上手难度最低（不用记命令）中中

建议三个都装一遍。不是为了日常都用，而是为了获得一个对比的经验：同一个模型放进不同的壳里，干活的风格真的不一样。这个体感一旦有了，你对「harness 决定能力上限」这句话的理解就再也不会忘。

还有一种情况：什么都别装 如果你只是想问问题、不碰文件，直接用聊天网页就好。
这句话不是客套。装工具有成本：要花钱、要配置、它还可能改错你的东西。不要因为「装工具看起来更专业」而去装它。

一个常见误解

「装了 Claude Code，是不是就等于用上了 Claude 模型？」

不是。工具和模型是两件事。Claude Code 是 Anthropic 做的 harness，但只要你把地址改掉，它调用的是谁家的模型，完全由你决定。

这也正是本手册的做法：用 DeepSeek 的 Key 驱动 Claude Code 和 Codex，不需要另买 Anthropic 或 OpenAI 的账号。具体怎么配，后面几页会一步步带你做。

🧠
理解这一点之后，你会发现自己选工具的自由度大了很多：模型可以换、harness 可以换，两件事互不绑定。唯一的限制是协议要对得上——这个在配 Codex 那一页会用上。
