# 交作业前的自查清单

逐项检查，**每项都要给出「通过 / 不通过 / 不适用」和证据**。不要只说「看起来没问题」。

## 一、跑过了吗

- [ ] 代码能从零跑通一遍吗？把实际运行的命令和输出贴出来
- [ ] 有没有写死的路径（`/Users/xxx/...`）、写死的 API Key？
- [ ] 换台机器还能跑吗？依赖写进 README 或 requirements 了吗？

## 二、格式对吗

- [ ] 老师要求的文件名、目录结构、字数/页数限制
- [ ] 图表有没有编号、有没有标题、正文有没有引用到
- [ ] 中英文标点是否统一（这是最容易丢分的地方）

## 三、引用全吗

- [ ] 每一个引用都能在参考文献里找到，反过来也成立（**不能有多余的**）
- [ ] 数据来源标注了吗？哪个数字从哪篇文章来的
- [ ] 直接引用的原话加引号了吗

## 四、AI 使用声明

- [ ] 写了吗？没写就补上
- [ ] 写清了三件事：**用了什么工具、用来做什么、哪些部分是你自己做的**
- [ ] 不要让 AI 替你写「我不太确定」这类判断——这部分必须是你自己的话

## 五、最后一眼

- [ ] 通读一遍，把「随着……的发展」这种空话删掉
- [ ] 找一个没学过这门课的人看 30 秒，问他「这是在讲什么」

## 输出方式

给一张表：**检查项 / 结果 / 证据 / 需要改什么**。
**不许直接替我改**——先把问题列出来，我问你哪条再动手。
