## 怎么投屏 SVG

SVG 就是文本，**浏览器直接拖进去就能全屏看**，放大不糊（矢量图）。

```bash
open demo-assets/harness/01-harness如何控制模型.svg      # macOS
```

- 按 `⌘ +`（Windows `Ctrl +`）放大到铺满屏幕
- 深色投影仪上如果偏亮，把系统调成浅色主题即可（图本身是白底）
- **不要转成截图再用**——直接开 SVG，字不会糊

两张图的分工：

| 图 | 讲什么 | 一句话 |
|---|---|---|
| `01-harness如何控制模型.svg` | **控制结构**：模型在中间，外面一圈是 Harness；五步怎么转、闸门在哪、结果怎么回到上下文；底部一张「模型做不到的五件事」对照 | 模型只会「文字进、文字出」，是 Harness 让它能干活并且不闯祸 |
| `02-循环工程四道缰绳.svg` | **四道控制**：笼头（看见什么）· 缰绳（能碰什么）· 勒停（什么时候停）· 回缰（错了怎么办），每道都有「太紧/太松」两个失败模式 | 写一个循环只要几十行，难的是这四件事 |

## 论文这一份怎么用

`paper/怎么读这篇论文.md` 不是给老师看的教案，**是能直接发给同学的阅读指南**。里面有：

- 论文来源与授权说明
- 一分钟了解这篇论文干了什么（三句话）
- **最短阅读路线**：只有 40 分钟的话读哪 7 处，哪几节可以跳过
- 读完应该能回答的 6 个问题（就是验收标准）
- 最容易搞混的 5 个术语（附「容易错在哪」）
- 三个常见误解（其中两个正好能接回课程主线）
- 关键数字速查（**每一个都回原文核对过**）

> 已经核对并纠正过一个坑：训练时长是 **base 12 小时 / big 3.5 天**（不是反过来）。base 版只有 **6500 万参数**——这个数字在讲「模型是买来的，循环是设计出来的」时很好用：它赢在结构，不在规模。

## skill 这一份怎么用

**两分钟就能讲完**，脚本在 `skills/README.md`，四步：

1. **看一个真实的**（20 秒）：Cursor 内置的 `shell`，867 字节，全文投屏
2. **description 的 A/B 对比**（40 秒）★ 最有说服力：同一份正文，好描述会被自动触发，坏描述永远不触发
3. **现场写一个当场生效**（40 秒）：复制进去，敲 `/` 就能看到
4. **（可选）三个真实 skill 各代表一种写法**：description 范本 / 编排型 / 大块头

> 里面有一步 **A/B 对比**要提前把两个 skill 都装上，课前花一分钟做完，见脚本开头的「课前准备」。

## 一个需要老师知道的差异

我核对了 DSH 的源码：**站点 Skill 那页混了 Claude Code 和 DSH 的能力。**

- DSH 只扫 `~/.dsh/skills/` 和 `项目/.dsh/skills/`，**不扫 `.claude/skills/`**
- DSH 只支持 `name`、`description`、`disable-model-invocation` 三个字段
- `$ARGUMENTS`、`!`命令``、`context: fork`、`agent:`、`allowed-tools` 在 DSH 全部自带包里**没有任何痕迹**

上课时的说法建议写成：「这一页的路径和进阶用法**以 Claude Code 为准**；你们第 2 节课先用 DSH，DSH 只认 `.dsh/skills`，够用了。」

完整对照表在 `skills/README.md` 末尾。
