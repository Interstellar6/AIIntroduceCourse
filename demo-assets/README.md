## 一、两张 harness 图

浏览器直接拖进去全屏看，矢量图放大不糊（`⌘ +` 放大）：

```bash
open demo-assets/harness/01-agent和harness差在哪.svg
```

| 图 | 什么时候放 | 讲什么 |
|---|---|---|
| `01-agent和harness差在哪.svg` | **第七段 · Harness**（16.9–20.7 分） | 三个词的分工 + 嵌套关系 + Harness 比机制多出来的五样 |
| `02-循环工程四道缰绳.svg` | **第六段 · Loop Engineering**（Agent 循环后半） | 笼头 · 缰绳 · 勒停 · 回缰，每道都有「太紧/太松」 |

第一张图的三段递进：

1. **三个词各回答什么问题** —— 模型 = 能力来源；**Agent = 一套机制，是个开关**（能不能动手）；**Harness = 一个产品，是个刻度**（动手动得多好、会不会闯祸）
2. **关系是包起来的** —— Harness 把 Agent 机制（五步循环）装在里面当内核，外面还多管六件事
3. **Harness 比机制多出来的五样** —— 每样都写了「没有它会怎样」

> 收尾那句是全图的落点：**这五样没有一样是模型的智力，全都是工程。**
> 所以除了「哪个模型更强」，你还有另一层可以挑、可以调 —— 就是这门课要教的那层。

**这张图不能把 Harness 换成 Agent。** 早先有一版画的是「循环 / 工具 / 日志 / 闸门」，
那正好是站点对 **Agent** 的定义，标题换成 Agent 也成立，等于没讲出 Harness 的特殊性，所以重画了。

## 二、论文

`paper/怎么读这篇论文.md` **是能直接发给同学的阅读指南**，不是教案。里面有：来源与授权、一分钟了解这篇论文、**最短阅读路线**（只有 40 分钟读哪 7 处、哪几节可以跳）、读完要能回答的 6 个问题、最容易搞混的 5 个术语、三个常见误解、关键数字速查（都回原文核对过）。

发下去时配一句话：

> 这是任务四要读的那篇论文。**别现在就读**——它是 2017 年的正论文，硬啃会劝退。
> 旁边那份《怎么读这篇论文》才是重点：里面写了只读哪 7 处、读完要能回答哪 6 个问题。

⚠️ **授权**：arXiv 的 **non-exclusive-distrib**，只授权 arXiv 分发，**没有**授权第三方再分发。
所以 PDF 已加进 `.gitignore`，**不进公开仓库、不进站点**；课堂直接发文件没问题，想放网上请只放链接：https://arxiv.org/abs/1706.03762

## 三、Skill 演示（两分钟）

**课前准备**（1 分钟）：

```bash
mkdir -p ~/.dsh/skills
cp -R demo-assets/skills/现场演示-读论文-SKILL.md ~/.dsh/skills/read-paper.md
```

> ⚠️ **DSH 只扫 `~/.dsh/skills/` 和 `<项目>/.dsh/skills/`**，不读 `.claude/skills/`。
> 每个工具只认自己那个目录，路径不要混。

**演示顺序**：

1. **看一个真实在用的**（20 秒）——打开 `skills/真实在用的-skill示例.md`：
   这是 Cursor 编辑器里正在用的 skill，**全文 867 字节**。结构就三块：`---` 里的元信息、一个标题、五条行为要求。
   然后指出最后一行 `disable-model-invocation: true`：
   > 为什么要把自己藏起来？因为它会直接执行终端命令。让模型自己决定什么时候用太危险，所以作者关掉了自动触发——**只能人来叫它。**

2. **description 决定它会不会被触发**（40 秒，**最有说服力**）——
   把 `现场演示-读论文-SKILL.md` 里的 description 改成 `帮助处理论文。`，放进 skills 目录，再问一句普通的话：
   > 这个目录里有一篇论文，帮我读一下。

   它会**完全不理会**这个 skill。然后改回具体描述，再问一次，它就会加载。
   > 模型看不到正文，它每一轮只能看到**名字和 description 那一句话**。
   > 「帮助处理论文」在它眼里等于什么都没说。**描述里写「什么时候用」，比写「它是什么」重要得多。**

3. **现场写一个，当场生效**（40 秒）——复制文件进去，敲 `/`，菜单里就多了一个。
   > 我刚做的事是：**写了一个 Markdown 文件。** 没写代码、没装东西、没改内核。
